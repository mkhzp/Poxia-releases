# Poxia

A Windows workspace for coding agents, projects and conversations.

## Download

Get the latest **Poxia-Setup-…-x64.exe** from [Releases](https://github.com/mkhzp/Poxia-releases/releases/latest) and run it. No GitHub account is needed.

The installer isn't code-signed, so Windows SmartScreen may warn the first time. Choose **More info → Run anyway**. You can check the download against `SHA256SUMS.txt` on the same release.

## Updates

Open **Settings → General → About → Check for Updates**, choose **Download update**, then **Restart & update**. Poxia verifies the installer's checksum before installing.

This repository holds installers and public artwork only. Poxia runs entirely on your own computer.
